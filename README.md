### 📂 Portfolio Structure & Projects

#### 01. Supervised Machine Learning
*Focus: Predictive modeling using Regression and Classification algorithms.*
- **❤️ [Heart Disease Classification](01-supervised_ml/heart_disease_classification)**: Three regression model variants were tested (LR, LD, and QD). All three were evaluated, and the final selection was based on overall performance and stability across folds. Additional experiments included SVC/SVR with GridSearch and Decision Trees.
- **⚖️ [Breast Cancer KNN & Naive Bayes](01-supervised_ml/breast_cancer_knn_nb)**: Implementation of KNN and Naive Bayes classifiers for tumor classification.
- **🚲 [Bike Rental Prediction](01-supervised_ml/bike_rental_prediction)**: Regression model predicting rental volume based on seasonal and weather data.
- **🐟 [Fish Weight Regression](01-supervised_ml/fish_weight_regression)**: Predicting fish weight using linear regression and EDA from aquarium dataset.

#### 02. Data Science & EDA
*Focus: Extracting insights from raw data through cleaning, visualization, and clustering.*
- **🗽 [NYC Airbnb Market Analysis](02-data_science_eda/nyc_airbnb_analysis)**: Exploratory Data Analysis of Airbnb pricing and trends using Pandas & Seaborn.
- **🌍 [Mall Customers Clustering](02-data_science_eda/mall_customers_clustering)**: Customer segmentation using KMeans and clustering validation techniques.
- **🔍 [Clustering Validation](02-data_science_eda/clustering_validation)**: Methods to evaluate clustering performance and detect outliers in datasets.
- **🚢 [Titanic Data Preparation](02-data_science_eda/titanic_data_preparation)**: Data cleaning, normalization, and preparation for supervised ML tasks.

#### 03. Deep Learning
*Focus: Neural Networks, Computer Vision, and synthetic data generation.*
- **🖐️ [Real-Time Finger Gesture Recognition](03-deep_learning/finger_gesture_recognition)**: Convolutional model trained to detect finger positions and predict how many fingers are raised in an open hand.
- **🧠 [Heart Failure Prediction NN](03-deep_learning/heart_failure_nn)**: Neural Network model predicting mortality in heart failure patients.
- **🚗 [Synthetic License Plate Generator](03-deep_learning/synthetic_license_plate_generator)**: GAN-inspired model to generate synthetic license plate data for OCR testing.
- **✈️ [Travel Image Classifier](03-deep_learning/travel_image_classifier)**: Feature extraction using VGG16 (ImageNet) and retrained classifier for destination recognition (beach vs mountain).

#### 04. Natural Language Processing
*Focus: Text analysis, sentiment, and semantic processing.*
- **📝 [Spanish Sentiment Analysis](04-nlp/sentiment_analysis.ipynb)**: Sentiment classification and analysis of Spanish-language text datasets.

#### 05. Classical AI & Search Algorithms
*Focus: Solving state-space problems using heuristic and uninformed search strategies.*
- **🏔️ [Terrain Optimization](05-classical_ai/terrain_optimization)**: Genetic Algorithms to find maximum and minimum altitudes for practical applications.
- **🧭 [Maze Navigation Agent](05-classical_ai/maze_agent)**: Agent-environment simulation navigating mazes with fully and partially observable strategies.

#### 06. Knowledge-Based Systems & Search
*Focus: Rule-based systems and document retrieval engines.*
- **📄 [Document Search Engine](06-knowledge_systems_search/document_search_engine)**: Python tool to index and query PDF documents using NLTK, Whoosh, PDFQuery, and optional speech support.
